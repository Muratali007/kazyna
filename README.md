# Казына — семейный бюджет

Сайт и Telegram-бот для общего семейного бюджета. Члены семьи пишут траты в Telegram обычным текстом
(«продукты 5400», «такси 1 500», «+300000 зарплата»), а Казына сама считает:

- сколько потрачено за месяц и сколько осталось (в том числе «≈ X ₸ в день»);
- сколько лежит на депозите и в целях;
- что осталось купить из списка покупок на месяц;
- лимиты по категориям, с предупреждениями в Telegram при 80% и 100%.

На сайте есть регистрация, приглашение в семью по ссылке, графики (кольцо бюджета, расходы по категориям, траты по дням, динамика за 6 месяцев), операции с фильтрами, бюджет и лимиты, цели, покупки, счета и депозит, экспорт в CSV. Сайт рассчитан на телефон и устанавливается как приложение (PWA).

## Запуск локально

```bash
npm install
npm start                     # http://localhost:3000, база — SQLite в data/app.db
```

Чтобы бот работал локально (через long polling), задайте токен:

```bash
TELEGRAM_BOT_TOKEN=123:ABC npm start
```

## Тесты

```bash
npm test                                                     # SQLite в памяти
TEST_DATABASE_URL=postgres://postgres:postgres@localhost:5432/postgres npm test   # Postgres
```

Внимание: тесты пересоздают схему `public` в базе из `TEST_DATABASE_URL`. Боевую базу туда не указывайте.

Тесты поднимают сервер и заглушку Telegram Bot API. Они проходят полный сценарий: регистрация, семья и приглашения, операции, балансы, цели, покупки, лимиты. Бота тесты проверяют через webhook: привязку, разбор сообщений, кнопки, уведомления, групповой чат.

## Деплой (Render + Neon)

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/Muratali007/kazyna)

1. **Бот.** В [@BotFather](https://t.me/BotFather) выполните `/newbot` и получите токен. Чтобы бот видел сообщения в семейной группе, сделайте `/setprivacy` → выберите бота → **Disable**.
2. **База.** На [neon.tech](https://neon.tech) создайте проект и скопируйте строку подключения `postgresql://…?sslmode=require`.
3. **Код.** Загрузите репозиторий на GitHub.
4. **Render.** New → Blueprint → выберите репозиторий (возьмётся `render.yaml`). Заполните переменные:
   - `DATABASE_URL` — строка из Neon;
   - `TELEGRAM_BOT_TOKEN` — токен бота;
   Адрес сайта Render задаёт сам (`RENDER_EXTERNAL_URL`). При старте сервер ставит webhook `<адрес>/tg/webhook` с секретным токеном.
5. **Автодеплой.** Render → сервис → Settings → Deploy Hook. Сохраните ссылку в GitHub → Settings → Secrets → Actions как `RENDER_DEPLOY_HOOK`. После зелёных тестов на `main` workflow `test.yml` сам запускает деплой.
6. **Чтобы сайт не засыпал.** В GitHub → Settings → Secrets and variables → Actions → Variables добавьте `SITE_URL` с адресом сайта. Workflow `keepalive.yml` будет открывать `/healthz` раз в 10 минут.

| Переменная | Назначение |
|---|---|
| `DATABASE_URL` | Postgres. Если не задана, используется SQLite (`SQLITE_FILE`, по умолчанию `data/app.db`) |
| `TELEGRAM_BOT_TOKEN` | токен бота. Без него бот выключен, сайт работает |
| `PUBLIC_URL` | публичный адрес для webhook, ссылок-приглашений и ссылки на сайт в боте. На Render необязателен: берётся `RENDER_EXTERNAL_URL` |
| `JWT_SECRET` | секрет сессий. Если не задан, генерируется и хранится в базе |
| `TELEGRAM_MODE=polling` | принудительно включить long polling вместо webhook |
| `APP_TZ` | часовой пояс для «сегодня» (по умолчанию `Asia/Almaty`) |

## Как пользоваться ботом

1. Зарегистрируйтесь на сайте. Откройте «Семья» → «Привязать Telegram» → «Запустить» в боте.
2. Пригласите близких: «Семья» → «Скопировать» ссылку. Каждый привязывает свой Telegram.
3. Пишите боту в личку или добавьте его в семейный чат.

| Сообщение | Что произойдёт |
|---|---|
| `продукты 5к`, `такси 1 500`, `1.5к шаурма` | расход; категория определяется по словам |
| `кофе 1200 налом` | расход со счёта «Наличные» |
| `+300000 зарплата`, `зп 450к`, `кешбэк 2300` | доход |
| `в депозит 50000`, `снял с депозита 20000` | перевод между картой и депозитом |
| `снял наличные 20000`, `с карты на наличные 10000` | перевод между счетами |
| `цель машина 20000`, `из цели машина 5000` | пополнение цели или снятие из неё |
| `купить пылесос 80000`, `нужно купить молоко` | добавить в покупки на месяц |
| `вчера аптека 3400`, `05.11 обед 2000` | операция задним числом |
| несколько строк | несколько операций одним сообщением |

Команды: `/balance` `/month` `/today` `/goals` `/plans` `/undo` `/cats` `/help`. Бот понимает и слова: «баланс», «итоги», «отмена».
Под ответом есть кнопки «🏷 Категория» и «↩️ Отменить». В `/plans` есть кнопки «✅ Купили», они сразу записывают трату.

## Устройство

- `server/index.js` — Express, все API и раздача статики
- `server/db.js` — общий слой для SQLite и Postgres
- `server/finance.js` — деньги (хранятся в копейках), балансы, сводки
- `server/parser.js` — разбор сообщений
- `server/ops.js` — проверка операций, лимиты
- `server/bot.js` — Telegram Bot API без библиотек
- `public/` — SPA на ванильном JS: `app.js`, `charts.js` (SVG-графики), `styles.css`, `sw.js`
- `scripts/make-icons.js` — генератор иконок (`npm run icons`)
